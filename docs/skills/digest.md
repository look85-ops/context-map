# Skill: Digest — Context Map

Геополитический дайджест для переезжающих в Беларусь из РФ.

## Триггер

- `/digest` — ручной запуск в чате
- GitHub Actions: Mon/Wed в 06:00 UTC (cron: `0 6 * * 1,3`)
- `workflow_dispatch` в Actions

## Конфигурация

| Параметр | Значение |
|---|---|
| Модель (основная) | DeepSeek V3 (`bothub.ru`, `deepseek-chat`) |
| Модель (fallback) | Meta-Llama-3.3-70B-Instruct (GitHub Models) |
| Поиск | DuckDuckGo, 10 запросов × 3 результата |
| Блоклист | ria.ru, tass.ru, rt.com, ukraina.ru и др. (20 доменов) |
| Частота | Mon/Wed (было Wed/Fri) |
| Аудитория | Наташа, L&D специалист, гуманитарий |

## Структура дайджеста

1. **Обзорная карта** — тренд, риск, возможность (2-3 абз., связанных с переездом)
2. **Поле боя** — РФ / РБ / Украина / Мир
3. **Слабые сигналы** — 3-5 edge signals
4. **Устойчивые паттерны** — что подтверждается 3+ периодов
5. **Влияние на решения** — работа, недвижимость, деньги, отрасли (самый важный раздел)
6. **Сценарии на 1-3 мес** — базовый / эскалация / деэскалация
7. **Дополнительно** — слепое пятно

## Формат ссылок (строго)

Каждый абзац — минимум одна ссылка `[Название](полный URL с https://)`.
В конце — блок источников `[N](url)`.
Пост-обработка исправляет: голые `[N]`, `[Name]url` → `[Name](url)`, `[Name][url]` → `[Name](url)`, bare `(url)` → `[url](url)`, bare `https://` в строке → `[domain](url)`, добавляет `https://` где нет.

## Валидация (validate_digest)

- Все markdown-ссылки имеют протокол (`https://`)
- Нет голых `[N]` рефов
- Нет голых URL в скобках
- Нет code fence-обёртки
